Safety boundary

UG-GHRS does not predict ground failure, replace statutory inspections, determine whether an area is safe, or authorise work. Competent mine personnel retain all safety decisions.

WHY UG-GHRS IS DIFFERENT

Five layers beyond a basic hazard log.

Designed to connect underground observations with location intelligence, accountable action and reliable reporting across changing connectivity.

PROPOSED DIFFERENTIATORS
01 / MAP

Underground hazard intelligence

Links reports to shaft, level and working area, highlighting repeat locations and concentrations of unresolved hazards.

LIVE IN THIS DEMO · Hazard map + repeated-location view
02 / CLOSE THE LOOP

Verified corrective-action workflow

Tracks ownership, investigation notes, corrective actions and independent verification before a report can be closed.

LIVE IN THIS DEMO · Assignment + action history + verification
03 / LEARN

Trend and recurrence insights

Surfaces repeated hazards, critical reports and overdue actions so teams can investigate underlying causes and recurring patterns.

LIVE IN THIS DEMO · Rule-based risk insights
04 / CAPTURE

Context-rich, intelligent reporting

Captures a report reference, date/time, shift, worker identity field and structured underground location at submission.

LIVE IN THIS DEMO · Smart report form
05 / STAY CONNECTED

Wi-Fi aware, offline-resilient sync

Uses available network connectivity to submit reports. If the connection drops, reports queue on the device and sync with a server receipt when connectivity returns, with duplicate protection.

DEMO IMPLEMENTATION · Local queue + unique submission ID + server acknowledgement
